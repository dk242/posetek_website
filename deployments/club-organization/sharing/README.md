This candidate adds club authorization to the exact source serving the three sharing callables, preserving the existing unsigned protocol for unmigrated athletes. It is prepared and offline-tested; no production source, secret or IAM has been changed.

The original source ZIP was downloaded read-only from `createAthleteResultsShare` version 7. `getAthleteResultsShare` version 8 and `getAthleteSharedRepArtifacts` version 7 reported the same source-upload identifier and Firebase source hash. The ZIP SHA-256 is `dbafa77dd15e8258c1aca4ab3f0ff41797e8f76c70a7e3fc1041a9422ba3951e`. `source-manifest.json` pins every original and candidate byte hash. Existing `package.json`, `package-lock.json` and private runtime config are unchanged; no dependency was added. The actual private runtime config is never included in this repository.

The public overrides and `club-sharing.patch` show the complete scoped change:

- Any presence of `organizationId`, including null or empty, closes unsigned legacy issuance/read paths. Legacy nested profile IDs also check their top-level player before lookup or writes.
- Legacy Storage folder resolution is retained, but every actual target owner's top-level player is checked before any listing or signed URL. This closes historical or writable `storagePath` pointers into a migrated athlete while preserving nonclub historical paths.
- Club creation goes through the reviewed V2 HMAC issuer. Public reads dispatch existing club V2 tokens to signature verification, current membership/team checks, and the reviewed athlete/drill-specific Storage resolver. A V2 failure does not fall through to legacy authorization. The signature binds creator role, so an issued coach share cannot be forged into an admin share.
- All other serving index code is unchanged. Only the three named entrypoints are deployed from this source; unrelated exports are not redeployed.

The V2 module, path resolver and club-access helper are exact reviewed copies from `functions/`. `club-sharing-handlers.js` wraps the reviewed V2 handler bodies as raw functions so the live index can dispatch without creating a second Firebase app. Club reads recheck the player's organization boundary. Signed artifacts retain the existing 15-minute URL lifetime; an already issued URL remains valid until expiry even if later membership is revoked.
