## Coach overview and follow-ups candidate

The assigned roster now appears as soon as team authorization and roster resolution complete. Its athlete rows fill independently with four concurrent reads. Each overview reads the athlete's plans and at most 51 ended workout logs per source from the previous 30 days; the 51st document marks that source as truncated, and only 50 are rendered. Personal workout logs are queried only while the existing `personalWorkoutsEnabled` flag is true. Complete history and measured testing results load only after selecting an athlete, with current team authorization rechecked first. A selected athlete's full read supersedes an older overview response.

Team completed-workout and timer totals are labeled as 30-day ended-log figures and remain hidden if any athlete overview failed, is still loading, or reached the sample limit. Current active-plan counts use the full plan read. Per-athlete overview testing values say to open the athlete; no empty testing score is inferred from the omitted callable. The follow-up queue uses only complete current plan status and recorded ended logs from the 30-day window: no active plan, pain reported in an ending or skipped block, and an ended-early outcome. It shows the covered team and dates, links to the athlete, and reports incomplete coverage. Missing usage telemetry never becomes an inactivity label. Unfinished logs, including logs with old starts but no ending, are not treated as current activity or abandonment; a separate >24-hour review rule needs agreed copy and query semantics. Retest intervals remain undefined.

A deferred 200-athlete synthetic test confirmed that 199 athlete rows were delivered while the first athlete read remained unresolved, with no more than four reads active. This establishes nonblocking row delivery, not production p95 latency. Team access resolution, the shared config read, full plans per athlete, and selected-athlete all-time history still need measurement with representative deployed data. No deployment was performed from this branch.
